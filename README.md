# مِيقَات — مواقيت الصلاة على Ubuntu (Miqat-Prayer)

مشروع تطبيق خفيف لسطح مكتب Ubuntu/GNOME، يعرض **العدّ التنازلي للصلاة التالية مباشرة في الشريط العلوي** ويتيح الاطلاع على مواقيت اليوم والقبلة والتاريخ الهجري.

> **الحالة الحالية:** التأسيس وتوثيق المواصفات. لا توجد نسخة قابلة للتثبيت حتى الآن. أي أوقات مستخدمة في النموذج الأولي المقبل ستكون تجريبية وليست رزنامة رسمية.

## الوظائف المستهدفة

- اسم الصلاة التالية والوقت المتبقي إليها في شريط GNOME العلوي.
- بطاقة معلومات عند مرور الفأرة تتضمن المنطقة، وقت الصلاة، زاوية القبلة والتاريخ الهجري.
- عرض مواقيت الصلاة كاملة بالنقر، مع إعدادات المكان والجهة المرجعية.
- **الجزائر:** اليومية الرسمية لوزارة الشؤون الدينية والأوقاف، مع الفروق الخاصة بالمدن والصلوات؛ لا يعرض أي حساب احتياطي على أنه رسمي.
- **خارج الجزائر:** مصادر رسمية محلية حيث تتاح، أو مصادر حسابية دولية واضحة التصنيف.
- العمل دون اتصال مستمر مع الاستفادة من بيانات مخزنة محليًا والتحقق من المصدر.

## المشاريع ذات الصلة

- [Hidjri_Calendar](https://github.com/scientifica007/Hidjri_Calendar): مرجع التقويم الهجري القائم؛ يُراجع منطق التواريخ فيه قبل إعادة الاستخدام.
- [مِيقَات داخل AppHub](https://scientifica007.github.io/AppHub/miqat/): واجهة التقويم الهجري المنشورة.
- [GNOME JavaScript](https://gjs.guide/extensions/): الوثائق الفنية للإضافة.

**تنبيه:** المواقيت الرسمية والتواريخ الهجرية المثبتة ترتبط بالمصادر الصادرة عن الجهات المختصة. يجب إظهار المصدر وحالة التحقق وعدم الخلط بين الجدول الرسمي والتقدير الحسابي.
