# بيانات M0 التجريبية

مصدر البيانات الوحيد هو `createSampleDay()` في `core/schedule.js`. الأوقات مصطنعة
وثابتة: 05:30، 07:00، 12:30، 15:30، 18:00، 19:30. ليست نتيجة حساب فلكي،
وليست من رزنامة أو وزارة. يُنشأ اليوم الحالي والغد وفق `Africa/Algiers` باستخدام
GLib/IANA؛ يتجدد اليومان عند تغير التاريخ، بما فيه الرجوع بالساعة إلى يوم سابق.

كل سجل يحمل `sample: true` و`verification: unverified` ومعرّف المصدر
`miqat-m0-synthetic-v1`. قيمة `sourceType` هي `null` عمدًا: لا تقع هذه البيانات
ضمن `official-timetable` أو `authority-method` أو `international-calculation`.
يرفض مدقق M0 أي ادعاء بأحد هذه التصنيفات. لا يوجد استيراد شبكة أو محرك مصادر
إنتاجي بعد. تاريخ التغطية المعروض يخص العينة المصطنعة ولا يثبت صلاحية دينية.

المصدر الرسمي في M1 يحتاج منشورًا أصليًا، وتغطية مكانية وزمنية، وإصدارًا، وشروط
استخدام، ومطابقة مستقلة. الرابط أو بصمة الملف أو اجتياز مخطط بنيوي لا يكفي لإثباته.
