# نسخة نشر M0 النظيفة

## القرار والنطاق

M0 معتمد وظيفيًا. نسخة publish/m0-clean جاهزة للمراجعة النهائية؛ **لا دفع قبل إذن المستخدم**.
جُلب origin/main باستخدام git fetch --no-tags origin main، وظل أساسه ce1d291.
أُنشئ الفرع منه وأُجري git merge --squash dev/m0، ثم حُضّر Commit نشر واحد
بمؤلف وحافظ يستخدمان بريد GitHub العام من نوع noreply عبر إعداد خاص بالأمر.
يبقى dev/m0 بكامل تاريخه دون تغيير عند 32aac2e. لا نقل لـCommits التطوير إلى نسب فرع النشر.
لا تغيير للإضافة المثبتة أو إعدادات GNOME، ولا تشغيل لدورات التفعيل، ولا عمل على M1/M2.

## فحص الخصوصية

فُحصت جميع الملفات المتتبعة الـ29، بما فيها الشيفرة والسكربتات والوثائق وJSON،
وفُحصت أشجار التاريخ الموروث من origin/main وهوية مؤلفه وحافظه.
لم يُكشف عن كلمات مرور أو رموز وصول أو مفاتيح خاصة أو بريد شخصي أو مسارات
منزلية فعلية أو اسم جهاز أو عناوين شبكة خاصة وفق أنماط الفحص ومراجعة المحتوى.
لا ملفات .env أو مفاتيح SSH أو سجلات خام ضمن الملفات المتتبعة.
بقيت أسماء GitHub العامة وروابط المشروع ومعرّف الإضافة وAfrica/Algiers بوصفها
منطقة العينة المصطنعة، وبيئة Ubuntu 24.04 / GNOME 46 / Wayland اللازمة لوصف التوافق.
الفحص لا يضمن اكتشاف كل صيغة سر محتملة.

أزيلت تفاصيل الجلسة من دليل القبول: قائمة الإضافات الأخرى ومعرّفات العمليات
والتوقيتات الدقيقة والقياسات التفصيلية للعملية. بقيت نتائج الدورات وخلاصة الموارد
وتأكيد المستخدم البصري وحدود الاختبارات غير المنجزة دون تغيير معناها.
سكربت الاختبار الميداني يحفظ مخرجاته الخام مستقبلًا في مجلد مؤقت خاص خارج
المستودع بدل استبدال دليل النشر. لم يُشغّل في هذا التحضير، ولا تحتوي شيفرته بيانات جلسة فعلية.
يحافظ قيد dev/m0 على منع تشغيله من فرع النشر. يجب ألا تُنشر مخرجاته الخام.

  الوثائق والدليل ومسار إخراج سكربت الاختبار الميداني فقط.

- حجم ZIP المبني محليًا: 7501 بايت؛ SHA256:
  a76576d0e95307d18ab83c0d3e7ebdf3e3ce40a7cda9000fcbf0ff73bb90bd0d.

## بوابة النشر

قبل التسليم يُتحقق من أن والد Commit النشر هو origin/main وأن عدد Commits
الجديدة واحد، وأن Commits dev/m0 الثلاثة غير موجودة في نسبه وأن مرجع dev/m0
لم يتغير. يلزم عند الإذن بالنشر استهداف publish/m0-clean وحده صراحةً، دون
--all أو --mirror أو Force Push. لا يُنشر dev/m0 أو تاريخ التطوير الخاص.
