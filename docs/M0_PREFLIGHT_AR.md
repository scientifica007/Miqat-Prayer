# مراجعة ما قبل تثبيت M0

وثيقة تاريخية تسبق التثبيت. الحالة الحالية: M0 معتمد وظيفيًا؛ راجع M0_FIELD_ACCEPTANCE_AR.md.

الفرع: `dev/m0`. كانت الموافقة على التثبيت والتفعيل معلّقة وقت هذه المراجعة.

نتيجة إعادة الفحص في 2026-11-06: نجحت 12 حالة Node و6 فحوص GJS وفحص
St/Clutter والصياغة والبيانات الوصفية والتحزيم. لم يوجد تعارض UUID في الفحص
الملفي أو قائمة Shell. حجم الحزمة النهائية 7501 بايت، وبصمتها المطابقة لـSHA256SUMS:

```text
61fcd0a85de0d5409425b8cce1c1965c31886113a82873c347e07d5e783c32c9
```

## مراجعة دورة الحياة

راجعت enable/disable والمرور والإشارات ومؤقتي العرض والمرور. لا تُنشأ عناصر Shell
إلا داخل enable. يسبق إلغاء المؤقتات فصل الإشارات وتدمير العناصر، وتُفرّغ المراجع
بعد التنظيف. عند المغادرة أو فتح القائمة يُلغى انتظار المرور وتُخفى البطاقة؛ تصفّر
دالة المؤقت المنتهي معرّفه قبل إعادة SOURCE_REMOVE، فلا يُزال معرّف منتهٍ لاحقًا.

حُسّن مسار فشل التهيئة الجزئية: تُضاف العناصر إلى مالكها فور إنشائها، وتُسجل
ملكية البطاقة قبل تهيئة نصها؛ لا تُزال من chrome قبل إلحاقها، ويضمن finally
تدميرها حتى عند خطأ الإزالة. تحققت من removeChrome وfindMonitorForActor في
موارد GNOME 46 المثبتة. هذه مراجعة شيفرة وليست شهادة تشغيل للواجهة أو لغياب التسرب.

## الفحوص والتثبيت المقرر

- تشغيل `python3 scripts/verify.py` لا يثبت الإضافة: اختبارات Node وGJS، وفحوص
  الصياغة والبيانات الوصفية وبناء ZIP ومطابقة محتوياته للمصادر.
- `python3 scripts/preflight.py` فحص قراءة فقط: بصمة الحزمة وUUID في مجلدات
  إضافات المستخدم والنظام وmetadata وقائمة Shell. يُعاد قبل التثبيت لأن الحالة قد تتغير.
- مجلد التثبيت المقصود:
  `$HOME/.local/share/gnome-shell/extensions/miqat-prayer@scientifica007.github.io`.
  التثبيت للمستخدم العادي دون sudo.
- أمر التثبيت المخطط: `gnome-extensions install dist/miqat-prayer@scientifica007.github.io.shell-extension.zip`
  من مجلد المشروع، دون sudo أو --force. لا تعديل لإعدادات GNOME العامة.
- ملفات المصدر والاختبارات والوثائق تحفظ في commit محلي؛ المخرجات المولدة في dist
  مستثناة من Git عمدًا. تؤكد SHA256SUMS بصمة النسخة المحلية المبنية، ويقارن البناء
  كل ملف في ZIP بالمصدر قبل قبولها.

التعطيل والإزالة وخطة نقل مجلد الإضافة من طرفية افتراضية عند تعطل الجلسة موثّقة
في `M0_TESTING_AR.md`. لم يُستخدم --replace أو تُعطّل أي حماية، ولم تُثبت الإضافة.

مرجع نطاق تثبيت الإضافات للمستخدم والنظام:
https://teams.pages.gitlab.gnome.org/Websites/help.gnome.org/system-admin-guide/extensions.html

## قرار M2 المحفوظ للمتابعة بعد إتمام M0

طلب المستخدم اعتماد عرض زاويتي القبلة المغناطيسية والجغرافية، مع إعطاء الأولوية
للمغناطيسية واستخدام نموذج WMM للانحراف المغناطيسي. يُحدّث هذا القرار في المواصفات
بعد إتمام M0؛ لم تُغيّر مواصفات القبلة الآن ولم يبدأ تنفيذها. تظل القبلة غير متاحة في M0.
