# تجربة M0 على Ubuntu 24.04 / GNOME 46 / Wayland

الحالة بتاريخ 2026-11-06: نجحت تجربة المستخدم الأولى والدورات العشر؛ أكد المستخدم مؤشرًا واحدًا وعدّادًا طبيعيًا دون بقايا، واعتمد M0 وظيفيًا. راجع [تقرير القبول](M0_FIELD_ACCEPTANCE_AR.md). التعليمات التالية مرجع لإعادة التجربة وليست سجل نتائج.
أوقات مصطنعة فقط، لا يعتمد عليها للعبادة. لا قبلة ولا تاريخ هجري حقيقيين.

## قبل التثبيت

الإضافة مثبتة ومفعّلة الآن؛ لا تُعد تثبيتها بهذه التعليمات. الأوامر التالية مرجع للتثبيت الأول على بيئة جديدة.
احفظ أعمالك قبل اختبار إضافة جديدة داخل Shell، لأن الإضافة تعمل في عمليته.
لا تستخدم `sudo`، ولا تغيّر إعدادات GNOME العامة أو `disable-extension-version-validation`.
إن لم تكن نسختك GNOME 46 فتوقف؛ هذا هو الإصدار الوحيد المعلن دعمه.

```bash
cd "$HOME/Miqat-Prayer"
gnome-shell --version
python3 scripts/verify.py
python3 scripts/preflight.py
cd dist
sha256sum -c SHA256SUMS
cd ..
gnome-extensions info miqat-prayer@scientifica007.github.io
```

الأمر الأخير متوقع أن يفيد بعدم وجود الإضافة قبل أول تثبيت. إذا كانت موجودة
فتوقف وراجع نسختها أولًا؛ لا تستبدل إضافة موجودة باستخدام `--force` دون مراجعة.
لا تحتاج الفحوص تنزيل حزم أو الاتصال بالإنترنت.

يفحص `scripts/preflight.py` مجلدات إضافات المستخدم والنظام ومعرّفات metadata
وقائمة الإضافات المعروفة لدى Shell وبصمة الحزمة. لا ينشئ مجلد التثبيت ولا يكتب
إعدادات. مسار المستخدم الافتراضي عند عدم تخصيص `XDG_DATA_HOME` هو:
`$HOME/.local/share/gnome-shell/extensions/miqat-prayer@scientifica007.github.io`.
التثبيت المخطط بأداة GNOME تحت UID المستخدم دون sudo أو --force، وليس إلى /usr/share.

## التثبيت والتفعيل بعد الموافقة

```bash
cd "$HOME/Miqat-Prayer"
gnome-extensions install dist/miqat-prayer@scientifica007.github.io.shell-extension.zip
```

سجّل الخروج ثم الدخول إلى جلسة Wayland لتتعرف Shell إلى الإضافة الجديدة.
لا تستخدم `Alt+F2 r` أو `gnome-shell --replace` لإعادة تشغيل Shell على Wayland.
بعد الدخول:

```bash
gnome-extensions enable miqat-prayer@scientifica007.github.io
gnome-extensions info miqat-prayer@scientifica007.github.io
journalctl --user -b -f -o cat
```

أوقف متابعة السجل بـCtrl+C. إذا لم تعرض يومية المستخدم سجلات Shell فراجع:

```bash
journalctl -b /usr/bin/gnome-shell --since '10 minutes ago' --no-pager
```

لا تعالج تحذيرات جلسة اختبار بتعطيل Sandbox أو سياسات الحماية. جلسة GNOME داخل
نافذة ممكنة بالأمر `dbus-run-session -- gnome-shell --nested --wayland`، لكنها
ليست عزلًا كاملًا ولا دليلًا على نجاح الجلسة الحقيقية؛ لم تُشغّل ضمن الفحوص الحالية.

## قائمة القبول الميداني

- يظهر «تجريبي» مع اسم الصلاة والعدّاد. الأرقام LTR والعربية مقروءة دون اهتزاز
  ملحوظ في الشريط. هذه العينة مثبتة على مدينة الجزائر، بغض النظر عن منطقة النظام.
- تظهر بطاقة بعد نحو 300ms من المرور، وتختفي عند المغادرة أو النقر أو القفل أو
  تغيير الشاشات. لا تتلقى البطاقة النقرات أو التركيز. راجع الحواف والتكبير 100%/200%.
- تفتح قائمة اليوم بالنقر؛ الشروق ظاهر وموسوم بأنه مستبعد من العدّاد. تظهر التغطية
  والمصدر التجريبي والقبلة والهجري غير المتاحين. تصل للقائمة بلوحة المفاتيح
  (التركيز على الشريط ثم التنقل إلى المؤشر، Enter/Space، وEscape للإغلاق).
- راجع قراءة الاسم والوصف بقارئ الشاشة عند استخدامه؛ لا يفترض نجاحها من النصوص وحدها.
- في 19:30 ينتقل العدّاد لفجر الغد، وعند منتصف الليل يصبح جدول اليوم جديدًا.
  تُختبر هذه الحدود آليًا دون تعديل ساعة النظام؛ تحقق منها طبيعيًا ميدانيًا عند الإمكان.
- جرّب القفل ثم الفتح، والتعليق/الاستئناف. إن كان السبات متاحًا أصلًا جرّبه؛ لا تُفعّل
  السبات ولا تعدّل النظام لأجل الاختبار. يصحّح أول tick بعد الاستئناف العدّاد من الساعة
  الفعلية (نحو ثانية في حلقة أحداث غير محجوبة)، ويعيد إنشاء اليومين إذا تغيّر التاريخ.
- عطّل وفعّل عشر مرات يدويًا، ومنها التعطيل أثناء انتظار البطاقة وأثناء ظهورها وأثناء
  فتح القائمة. يجب ألا يبقى مؤشر أو بطاقة، ولا تظهر عناصر مكررة أو أخطاء تخص Miqat.
- قارن خمول Shell قبل التفعيل وبعده وبعد التعطيل عبر مراقب النظام. راقب استقرار
  استهلاك المعالج والذاكرة بعد الدورات؛ Shell عملية مشتركة فلا تنسب كل تغير إلى الإضافة.

## التعطيل والإزالة والتراجع

```bash
gnome-extensions disable miqat-prayer@scientifica007.github.io
gnome-extensions info miqat-prayer@scientifica007.github.io
gnome-extensions uninstall miqat-prayer@scientifica007.github.io
```

تُزيل الإضافة فقط، دون مساس بالمستودع أو غيرها من الإضافات. يُفضّل تسجيل الخروج
والدخول بعد الإزالة للتأكد من بدء عملية Shell نظيفة. لا تنشئ M0 إعدادات GSettings
أو بيانات مستخدم دائمة تحتاج إلى حذف منفصل.

إذا تعذر الوصول إلى الواجهة، استخدم طرفية افتراضية بـCtrl+Alt+F3 وسجّل الدخول
بالمستخدم نفسه، ثم انقل مجلد هذه الإضافة وحده إلى نسخة احتياطية:

```bash
mv -- "$HOME/.local/share/gnome-shell/extensions/miqat-prayer@scientifica007.github.io" "/tmp/miqat-m0-disabled-$(date +%s)"
```

لا تنفّذ النقل إذا كان المصدر غير موجود أو كان المسار مختلفًا؛ راجعه أولًا. ثم سجّل
الخروج والدخول من الجلسة الرسومية؛ قد يلزم إعادة تشغيل الجهاز إذا كانت الجلسة لا تستجيب.

## حدود التحقق الآلي

`python3 scripts/verify.py` يتوقف عند أول إخفاق، ويشغّل اختبارات Node، وفحص
صياغة JS والبيانات الوصفية، واختبارات GLib/IANA، وفحص واجهة اتجاه النص بالاستبطان،
وبناء الحزمة بأداة `gnome-extensions pack`. يتحقق البناء من قائمة الملفات ومطابقتها
للمصادر وسلامة ZIP ويكتب SHA256SUMS. لا يُنشئ أي ممثل رسومي ولا يثبت الإضافة.

اختبارات إدارة الموارد تستخدم كائنات بديلة؛ لا تثبت غياب تسرب في GNOME الفعلي.
اختبارات الوقت الصيفي تتحقق من يومي 23 و25 ساعة ومن رفض وقت غير موجود في باريس؛
الموقع المتاح في M0 هو الجزائر فقط، وسياسة الأوقات الملتبسة الدولية مؤجلة إلى M3.
