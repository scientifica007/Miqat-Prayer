# قبول M0 الميداني — 2026-11-06

الحالة: **M0 مقبول وظيفيًا** بموافقة المستخدم الصريحة بعد اجتياز الدورات والفحص البصري النهائي.
أوقات مصطنعة معلّمة؛ لا جاهزية للاعتماد الديني. لا تنفيذ لـM1 أو M2.

## البيئة والأدلة

بيئة القبول: Ubuntu 24.04 / GNOME 46 / Wayland.
فرع الاختبار الأصلي dev/m0؛ نسخة النشر publish/m0-clean. طابقت ملفات الإضافة المثبتة مصادر المستودع قبل الاختبار.
[ملخص الدليل المنقّح للنشر](evidence/m0-20261106.json) و[سكربت إعادة الاختبار](../scripts/m0-live-acceptance.py).
لا يُشغّل السكربت تلقائيًا؛ تشغيله على فرع التطوير يغيّر حالة Miqat مؤقتًا. تحفظ تفاصيله في مجلد مؤقت خاص خارج المستودع؛ لا تضاف مخرجاته الخام إلى Git. لم يُشغّل أثناء تحضير النشر.

أظهرت القياسات زيادة ذاكرة صغيرة متذبذبة دون نمو متتابع واضح؛ لا علامة فقدان موارد
كبير خلال النافذة القصيرة. القياس للعملية المشتركة وليس لـMiqat وحدها، ولا يثبت انعدام التسرب.
لم يُقس خمول معزول ولم تُحقن أدوات استبطان داخل Shell لعد المؤقتات والإشارات.
حُذفت تفاصيل القياسات والسجلات غير اللازمة للنشر؛ بقيت نتائج القبول فقط.
التحذيرات القديمة المفحوصة لم تُنسب إلى Miqat، ولم تُعدّل إضافات أخرى لمعالجتها.

## الأوامر والفحوص

- قراءة journalctl --user -b للعملية الحالية، مع cursor مستقل للرسائل الجديدة.
- gnome-extensions info/list --enabled قبل وبعد، وdisable/enable للمعرف miqat-prayer@scientifica007.github.io وحده.
- python3 scripts/m0-live-acceptance.py: توقف عند أي استثناء أو رسالة تحذير/خطأ جديدة أو تغير PID أو مجموعة الإضافات الأخرى.
- python3 scripts/verify.py: ناجح؛ SHA256 الحزمة 01137164f7aa70a72e25f3300fc384bcd0243b71f3449ee6c3e4301d84e77d85.

تعذر بدء العزل بسبب bwrap/RTM_NEWADDR؛ استُخدمت الموافقات للأوامر المحددة دون تغيير وسائل الحماية.
لم تثبّت حزم، ولم تعدّل إعدادات GNOME العامة، ولم تُستخدم --replace أو إعادة دخول تلقائية، ولم يحدث دفع بعيد.

## الحدود والعمل المتبقي

الدورات أُجريت في الحالة العادية؛ التعطيل أثناء انتظار/ظهور البطاقة أو فتح القائمة لم يُختبر بصريًا.
اختبارات القفل والاستئناف والتكبير 200% ولوحة المفاتيح وقارئ الشاشة والحدود الزمنية الطبيعية
تبقى اختبارات موسعة موثقة في M0_TESTING_AR.md، ولا تُسجل هنا كناجحة.
غياب رسالة في السجل لا يثبت منفردًا غياب كل تسرب أو خلل بصري.
